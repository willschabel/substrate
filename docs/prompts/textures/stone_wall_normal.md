# stone_wall_normal

Normal maps are derived from the albedo — do not generate directly from a text prompt.

## Workflow
1. Generate `stone_wall_albedo.png` first
2. Upload to https://cpetry.github.io/NormalMap-Online/
3. Strength: 4–6 (deep block seam grooves and surface pitting)
4. Export as PNG

## Notes
- Target deep relief — large block seams should produce strong normal displacement
- Surface pitting and crack edges should read clearly
- Circuit trace grooves should appear as shallow channels
