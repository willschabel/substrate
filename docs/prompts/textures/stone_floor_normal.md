# stone_floor_normal

Normal maps are derived from the albedo — do not generate directly from a text prompt.

## Workflow
1. Generate `stone_floor_albedo.png` first
2. Upload to https://cpetry.github.io/NormalMap-Online/
3. Strength: 3–5 (recessed grout lines should read clearly, tile faces nearly flat with subtle paint variation)
4. Export as PNG

## Notes
- Grout lines between octagon and diamond tiles are the primary relief — make them read strongly
- Tile faces should be nearly flat, worn smooth by foot traffic
- Crack edges across tile faces should read subtly
- Painted brushstroke micro-texture adds surface variation across tile faces
