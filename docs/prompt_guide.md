# Mood Board Prompt Guide

Reference this document when generating image prompts for any game asset. Every prompt
should feel like it belongs to the same world. Full setting context: [setting.md](setting.md)

**Max character limit: 480** (Bing Image Creator constraint)

---

## Aesthetic Rules (Prompt Vocabulary)

### Always Include (pick relevant ones per category)
- `ancient forgotten technology`
- `worn` `weathered` `time-worn` `centuries of age`
- `cracked stone with light bleeding through`
- `tarnished but still glowing` / `faded but still luminous`
- `still functioning but purpose unknown`
- `worn circuit traces still pulsing`
- `mysterious symbols no one can read`
- `sense of wonder and discovery`
- `concept art` `vibrant colors` `cinematic` `awe-inspiring`

### Never Include
- dark / gritty / grimdark / ominous / moody
- pristine / shiny / clean / new (except the grid itself)
- cold / eerie / threatening
- cyberpunk / neon / sci-fi city
- medieval fantasy / magic runes / elves
- plastic / chrome / glass panels

### Colour Palette (use these words in prompts)
| Role | Prompt Words |
|---|---|
| Structure | `weathered sandstone` `tarnished bronze` `worn grey stone` `aged iron` |
| Ancient tech | `faintly glowing blue-white circuitry` `cold teal tech glow` `holographic symbols flickering` |
| Patina & age | `verdigris` `oxidised copper` `warm rust` `worn leather` |
| Nature | `vibrant greens` `wildflower colors` `warm amber sunlight` |

### Tone Tail (end every prompt with a variation of this)
> `concept art, vibrant colors, cinematic, awe-inspiring`

For weapon/item close-ups:
> `product concept art, dark background, vibrant, detailed`

---

## The Grid

When the grid appears in a prompt (through windows, as sky, through canopy gaps):
> *"the grid visible [through X] like a [luminous sky / vast constellation] of perfect glowing blue geometry — pristine and eternal, untouched by age"*

The grid is always **pristine** — it is the one thing that has not aged. The contrast between the eternal grid and the worn world around it is intentional.

## Templates by Category

### Base Interior
```
[Describe scale — soaring / vast / grand] ancient chamber,
[describe ceiling — vaulted / arched / lost in golden light],
glowing circuit traces [describe pattern — running floor to ceiling / like luminous murals],
warm [color] light from unknown sources,
[describe nature present — moss / small flowering plants / vines through cracks],
mysterious symbols etched into every surface,
[additional wonder detail],
concept art, vibrant colors, cinematic, awe-inspiring
```
*Keep under 480 characters*

### Combat Location — Indoor
```
[Describe space — vast ancient hall / grand chamber / soaring corridor],
[describe architectural feature — vaulted ceilings / arched doorways / towering columns],
glowing circuit murals on the walls in warm gold and teal,
ancient machinery [describe state — still slowly turning / humming quietly],
luminous plants growing through the stone,
[describe light — warm golden / soft teal glow],
sense of discovery,
concept art, vibrant colors, cinematic, awe-inspiring
```
*Keep under 480 characters*

### Combat Location — Outdoor / Open
```
[Describe landscape — rolling hills / open valley / wide plains],
[describe nature — wildflowers / scattered ancient trees / clear stream],
[describe ancient tech presence — circuit traces glowing beneath soil / forgotten machinery half-buried],
[describe light — warm golden sunlight / amber light],
the grid visible [above / through gaps] like a [luminous sky / vast constellation] of perfect glowing blue geometry,
concept art, vibrant colors, cinematic, awe-inspiring
```
*Keep under 480 characters*

### Weapon — Melee
```
[Weapon type] with [describe base material],
[describe ancient tech integration — circuit-etched blade / glowing power cell / luminous etchings],
[describe craftsmanship — beautiful as much as functional],
[describe grip — rich leather / burnished metal],
warm [color] glow,
clearly crafted by someone who repurposed technology they didn't fully understand,
product concept art, dark background, vibrant, detailed
```
*Keep under 480 characters*

### Weapon — Ranged
```
[Weapon type] built around [describe ancient tech component — glowing power cell / ancient emitter],
[describe construction — crafted from reclaimed metal / hand-built],
[describe a visible repair or adaptation],
[describe grip — rich leather / warm wood],
[describe active tech — warm glow / pulsing light / luminous circuit etchings],
beautiful and mysterious, clearly built not bought,
product concept art, dark background, vibrant, detailed
```
*Keep under 480 characters*

### Enemy
```
[Silhouette / Full render] of an ancient autonomous [construct / guardian / system],
originally [describe purpose] but centuries of dormancy have not diminished it,
[describe elegant features — tall / graceful / softly glowing sensors],
ancient symbols still luminous on its surface,
beautiful and unknowable,
[describe environment],
sense of awe,
concept art, cinematic, vibrant
```
*Keep under 480 characters*

### Environment — Establishing Shot
```
[Wide / establishing shot of location],
[describe dominant landscape or architecture],
[describe ancient tech presence and its warm glow],
[describe nature if present],
[describe light],
[include grid if visible],
concept art, vibrant colors, cinematic, awe-inspiring, wide angle
```
*Keep under 480 characters*

### UI / Interface Element
```
Ancient holographic interface [describe what it shows],
projected in warm gold and soft teal light,
surrounded by symbols in a dead language,
[describe physical housing],
beautiful and impossible to fully understand,
concept art, dark background, vibrant, detailed
```
*Keep under 480 characters*
